# Evidencias Semana 3

Este directorio centraliza la evidencia auditable de la Semana 3.

## Objetivo
Registrar evidencia técnica verificable para revisión de pares, mentores o auditoría:
- Cumplimiento de rúbrica
- Resultado de pruebas automatizadas
- Evidencia visual y trazabilidad

## Contenido
- `CHECKLIST_RUBRICA_SEMANA3.md`: estado por criterio de la rúbrica.
- `RESULTADOS_TESTS_SEMANA3.md`: resumen de ejecuciones y rutas de artefactos.
- `capturas/`: screenshots de suite en verde y/o pipeline.
- `artifacts/`: reportes exportados (`.trx`, coverage, etc.) cuando aplique.

## Convención sugerida
- Fecha en formato `YYYY-MM-DD`.
- No subir logs gigantes sin resumen.
- Cada resultado debe incluir comando ejecutado y salida resumida.
