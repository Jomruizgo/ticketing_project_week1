Construye una feature de inscripción para un sistema de lista de espera dentro de una plataforma de venta de entradas existente. Cuando un evento no tiene entradas disponibles de inmediato, un comprador puede registrar su interés proporcionando su correo electrónico. El sistema crea una inscripción en lista de espera con estado 'active'. Reglas de negocio: un comprador no puede tener más de una inscripción activa para el mismo evento (unicidad aplicada a nivel de aplicación y de base de datos mediante partial unique index). La lista de espera cierra cuando se alcanza la fecha del evento: no se aceptan inscripciones después de eso. Un comprador cuya oportunidad anterior fue consumida o expirada puede reinscribirse mientras la lista esté abierta. La inscripción no reserva ninguna entrada; solo registra la intención del comprador. El comprador se identifica únicamente por correo electrónico: no existe sistema de autenticación. El endpoint de la API es POST /api/waitlist/entries, recibe { eventId, buyerEmail } y devuelve 201 con la inscripción, 409 si es duplicada, o 422 si la lista de espera está cerrada.
