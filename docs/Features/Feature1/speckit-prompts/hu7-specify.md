Build the frontend enrollment experience for the waitlist feature. In the existing Next.js/React application, when a buyer navigates to an event page and the event has no immediately available tickets, the application shows a waitlist enrollment option instead of the direct purchase button. The buyer enters their email and submits. On success, the application confirms their enrollment and shows the inscription as active. If the buyer is already enrolled (409 response), the application informs them without creating a duplicate. If the event date has passed and the waitlist is closed (422 response), the application shows that the waitlist is no longer accepting enrollments. The enrollment form is only visible when: (1) the event has no available tickets and (2) the waitlist is still open (event date not reached). When tickets are available, the normal purchase flow is shown instead. The API interaction uses POST /api/waitlist/entries with { eventId, buyerEmail } from the CRUD Service.
