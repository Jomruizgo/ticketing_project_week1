Construye la experiencia frontend de estado y acción sobre oportunidad para la feature de lista de espera. En la aplicación Next.js/React existente, un comprador inscrito puede verificar su estado en la lista de espera y actuar sobre una oportunidad activa. La aplicación muestra cuatro estados distintos: (1) inscripción activa (en espera, sin oportunidad aún), (2) oportunidad activa (entrada reservada temporalmente, cuenta regresiva con tiempo restante en minutos), (3) oportunidad consumida (avanzó al pago), (4) oportunidad expirada (el tiempo se agotó, sin reserva). Cuando el comprador tiene una oportunidad activa, la aplicación muestra un botón prominente 'Avanzar al pago' y una cuenta regresiva con el tiempo de validez restante. Al hacer clic llama a POST /api/waitlist/opportunities/{id}/claim con el correo del comprador. En caso de éxito (200), la oportunidad pasa a 'consumed' y el comprador es redirigido al flujo de pago con la entrada reservada. Si la oportunidad expiró (409), la aplicación muestra un mensaje de expiración. Si el correo no coincide (403), se muestra un error. La vista de estado se actualiza en tiempo real mediante conexión SSE a GET /api/waitlist/stream?email={email}: cuando llega un evento opportunity_activated, la UI transiciona de 'en espera' a 'oportunidad activa' sin recarga de página; cuando llega opportunity_expired, la UI transiciona a 'expirada'.
