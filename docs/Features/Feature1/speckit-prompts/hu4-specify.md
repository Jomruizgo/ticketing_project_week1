Build an in-app notification feature for the waitlist system. When a buyer's waitlist opportunity becomes active (ticket reserved temporarily for them), the system pushes a real-time notification to the buyer inside the application without requiring a page refresh. The notification channel uses Server-Sent Events (SSE). The buyer connects to a persistent SSE stream filtered by their email. When an opportunity is activated, the system emits an opportunity_activated event containing: opportunityId, ticketId, eventId, expiresAt, and remainingMinutes (default 15 minutes). When an opportunity expires, the system emits an opportunity_expired event containing: opportunityId, eventId, and reason. The buyer sees their opportunity status update in real time: that a ticket is temporarily reserved for them and how much time they have left. If the buyer navigates away and comes back, querying their status still shows the active opportunity as long as it hasn't expired. The SSE endpoint is GET /api/waitlist/stream?email={email} with content type text/event-stream.
