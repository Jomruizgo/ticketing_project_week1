# Prompts para Spec Kit — Épica Lista de Espera

Este directorio contiene los prompts listos para pasar a los comandos de spec-kit (`/speckit.constitution`, `/speckit.specify`, `/speckit.plan`) para cada historia de usuario de la épica.

## Orden de uso

1. **Constitución** (una sola vez para toda la épica): [`constitution.md`](constitution.md)
2. **Specify + Plan** (una vez por HU, en orden):
   - [`hu1-specify.md`](hu1-specify.md) → [`hu1-plan.md`](hu1-plan.md)
   - [`hu2-specify.md`](hu2-specify.md) → [`hu2-plan.md`](hu2-plan.md)
   - [`hu3-specify.md`](hu3-specify.md) → [`hu3-plan.md`](hu3-plan.md)
   - [`hu4-specify.md`](hu4-specify.md) → [`hu4-plan.md`](hu4-plan.md)
   - [`hu5-specify.md`](hu5-specify.md) → [`hu5-plan.md`](hu5-plan.md)
   - [`hu6-specify.md`](hu6-specify.md) → [`hu6-plan.md`](hu6-plan.md)
   - [`hu7-specify.md`](hu7-specify.md) → [`hu7-plan.md`](hu7-plan.md)
   - [`hu8-specify.md`](hu8-specify.md) → [`hu8-plan.md`](hu8-plan.md)

## Cómo usar

Copiar el contenido de cada archivo y pegarlo como argumento del comando spec-kit correspondiente en tu agente de IA.
