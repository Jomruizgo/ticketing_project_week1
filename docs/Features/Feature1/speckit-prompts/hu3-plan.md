The opportunity assignment feature spans the CRUD Service (crud_service/) for persistence and domain logic, and consumes events from RabbitMQ. Architecture is hexagonal: Domain, Application, Infrastructure, Api. Use .NET 8 with EF Core for PostgreSQL. Create a WaitlistOpportunity entity in Domain with fields: Id, WaitlistEntryId, TicketId, Status (pending/active/consumed/expired/failed), ActivatedAt, ExpiresAt. Define the OpportunityStatus enum with allowed transitions: Pending→Active, Pending→Failed, Active→Consumed, Active→Expired. Implement an IPrioritizationStrategy port in Domain/Interfaces with a FifoStrategy adapter in Infrastructure that queries the earliest active enrollment for the event. Create an AssignOpportunityCommand and AssignOpportunityHandler implementing IAssignOpportunityUseCase in Application/UseCases. The handler: (1) queries IPrioritizationStrategy for the next eligible buyer, (2) if none, returns "no eligible" so the ticket returns to inventory, (3) if found, calls ITicketReservationPort to reserve the ticket temporarily, (4) if reservation fails, logs and returns without creating opportunity, (5) if reservation succeeds, creates WaitlistOpportunity with status active, sets expiresAt = now + TTL, marks the enrollment as inactive, (6) publishes opportunity_activated event via IOpportunityObserver (Observer pattern). Define IOpportunityObserver port in Domain/Interfaces. Create a TicketReleasedConsumer in Infrastructure/Messaging that listens to the ticket.released routing key and invokes the use case. The consumer ACKs on success or business failure, NACKs with requeue:false on technical failure. The opportunity is published to RabbitMQ DLX queue for expiration: q.waitlist.opportunity.delay with TTL, dead-lettered to q.waitlist.opportunity.expired. Database table waitlist_opportunities uses snake_case columns. TDD: test handler with eligible buyer + successful reservation, eligible buyer + failed reservation, no eligible buyer. Use Testcontainers for integration tests verifying the FIFO query and unique constraint.
