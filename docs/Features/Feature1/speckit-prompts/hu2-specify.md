Build a status query feature for the waitlist. An enrolled buyer can check their current status by providing their email and eventId. The system returns the buyer's enrollment status and, if an opportunity exists, its current state (active with remaining time, consumed, or expired). When the opportunity is active, the response includes the remaining minutes of validity and indicates that a ticket is temporarily reserved. When expired, no reservation is shown. When no enrollment exists, the system returns 404. The four possible states the buyer can see are: active enrollment (waiting), active opportunity (ticket reserved, time running), consumed opportunity (advanced to payment), expired opportunity (time ran out). The API endpoint is GET /api/waitlist/entries?eventId={id}&email={email}.
